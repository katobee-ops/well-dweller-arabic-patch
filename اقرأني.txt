# Well Dweller - Arabic Translation Patch

This repository contains the **full source code** of the installer scripts used in the
Arabic translation patch for the game "Well Dweller".

## What this patch does

It applies a binary diff (using the open-source tool `xdelta3`) to the user's own
legally-owned copy of `data.win` and `translations.ini`, translating all in-game text
to Arabic. No copyrighted game files are distributed — only the binary difference
(patch) between the original and the translated version.

## Files in this repository

- `تطبيق_التعريب.bat` — Installer script (plain text, Windows Batch). Backs up the
  user's original files, then applies the patch using `xdelta3.exe`.
- `استعادة_الأصلي.bat` — Restore script (plain text, Windows Batch). Restores the
  user's original backed-up files.
- `اقرأني.txt` — Instructions for end users, written in Arabic.

Both `.bat` files are plain text and are not compiled — the content of this
repository **is** their full source code, unmodified.

## About xdelta3.exe

The only compiled binary included in the distributed package is `xdelta3.exe`,
which is a well-known open-source binary diff/patch tool. It was **not modified
in any way**; it is the exact official unmodified build.

- Official source code and build instructions: https://github.com/jmacd/xdelta
- Official releases page: https://github.com/jmacd/xdelta/releases
- Exact release used in this patch: [xdelta3-3.2.2-windows-x86_64]

Anyone can verify the binary included in the package matches the official release
by comparing its SHA-256 hash with the one from the official GitHub release page.

## How the patch files (.xdelta) were created

The `.xdelta` patch files are not executable code — they are binary diff data
generated with the following command:
xdelta3.exe -e -9 -s original_data.win data_arabic_translated.win data_patch.xdelta
xdelta3.exe -e -9 -s original_translations.ini translations_arabic_final.ini translations_patch.xdelta

This simply records the byte-level differences between the original English files
and the translated Arabic version, so it can be applied on top of a legitimately
owned copy of the game.
